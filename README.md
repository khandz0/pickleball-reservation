# Pickleball Court Reservation System

A RESTful API for finding and booking pickleball courts.

## Features

- User authentication (JWT)
- Find nearby courts using Google Maps API
- Reserve courts and check availability

## Setup

1. Clone the repository
2. Install dependencies
3. Set up environment variables

## Tech Stack

- Node.js (Express)
- PostgreSQL
- Redis (for caching)
- Google Maps API
